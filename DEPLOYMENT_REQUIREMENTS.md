# Verpex reseller account qualification

Reviewed 5 November 2026. An authenticated, read-only inspection of the cbidinstitute.com client account confirmed cPanel 136.0.51 and the account home /home/cbidinstitute. The public HTTP response identifies LiteSpeed. The panel exposes Node.js Selector, Application Manager, PostgreSQL tools, MySQL tools, Terminal/SSH, Cron Jobs, SSL, PHP/Python selectors, Backup Wizard and Backuply. Node 24.22.2 and npm 11.19.1 execute in Terminal. Database security privileges and actual application execution still require checks. UNKNOWN below means an acceptance check remains outstanding. No production application or database was created during this inspection.

**Decision.** Preserve the existing API and database semantics for the staging candidate. It uses one Node process serving the API and a prebuilt React application. The local build runtime is Node v24.22.0; the verified host runtime is v24.22.2 and requires release-level staging checks. A separate web dev server and Redis are unnecessary with one process. The PostgreSQL RLS/grants, security-definer functions, advisory locks, hashed session tokens, quiz grading and audit logic require a validated migration before moving to another engine. If both local and external PostgreSQL are unavailable but Node + MariaDB pass, prefer a scoped Node + MariaDB migration over replacing both the language and database. If only PHP + MariaDB pass, plan a PHP port. A Python port requires a verified interpreter and an additional full backend rewrite. The decision record must be reopened if these account checks fail.
